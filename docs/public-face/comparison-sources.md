# Alternative and boundary sources

Checked 2026-08-30. These are source links for the README's scope comparison,
not a ranking. Projects evolve; use their own documentation for current detail.

| Project | Public source used for the narrow claim |
| --- | --- |
| Direct repository search | No product claim: it reads the source directly, without a retained architecture-context contract. |

| GyroCompass | [README](https://github.com/gyrocompass-io/gyrocompass): Tree-sitter architectural extraction, rules, drift reporting, and agent MCP tools. |
| CodeDebrief | [README](https://github.com/ferdinandobons/CodeDebrief): deterministic source-grounded workflow maps and bounded MCP workflow slices. |

LAC does not claim to replace any of these. Its narrow contract is to bind a
small set of canonical/truth-source claims to current source evidence and tell
an Agent whether the retained orientation is fresh enough to use.
